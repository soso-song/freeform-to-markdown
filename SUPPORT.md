# Support

## Ask a question

Use [GitHub Discussions](https://github.com/soso-song/freeform-to-markdown/discussions) for setup,
workflow, archive interpretation, and contribution questions. Search existing discussions and the
[documentation](README.md#documentation) first.

## Report a problem

Use the repository's structured issue forms for reproducible bugs, compatibility reports, and
feature requests. Include synthetic data only. The project cannot accept private boards,
databases, assets, screenshots, exported archives, credentials, or personal information for
troubleshooting.

Run these commands before filing a report:

```bash
freeform-to-markdown doctor
freeform-to-markdown verify "path/to/archive"
```

Remove local paths, board titles, object content, and personal identifiers from any output you
share.

## Security and privacy reports

Do not use a public issue. Follow [SECURITY.md](SECURITY.md).

## Support expectations

This is a volunteer open-source project. Responses and fixes are best effort, and no service-level
agreement is offered. Unsupported Freeform schema fingerprints may require a synthetic fixture and
a contributor who can test on the affected macOS version.
